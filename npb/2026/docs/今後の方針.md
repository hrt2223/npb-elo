その通りです。現時点で確認できているのは \(\gamma\) の最適化までで、K値や先発投手成績など、どの補正が有効かは未検証です。

## 1. 研究目的

NPB公式戦を対象として、チームのEloレーティングを用いた勝敗予測モデルを構築し、野球に適したパラメータを検討する。

現段階では、ホームアドバンテージおよびロジスティック定数 \(\gamma\) を導入したチームEloモデルを構築している。今後は、K値、チームの直近成績、当日の先発投手成績などの補正候補を導入し、どの補正が勝敗予測の精度向上に有効であるかを検証する。

> NPBの勝敗予測において、チームEloレーティングへどのような補正を加えることが予測精度の改善に有効か。

## 2. 現状

2001年から2025年までのNPB公式戦21,237試合を用いて、ホームアドバンテージを考慮したEloレーティングによる勝敗予測を行った。

- 初期レーティング：1500
- K値：24（暫定値）
- ホーム勝率：54.02%
- ホームアドバンテージ：ホーム勝率から導出
- \(\gamma\)：200から3000まで50刻みで比較

その結果、一般的なEloで用いられる \(\gamma=400\) では予測的中率54.41%であったのに対し、\(\gamma=2050\) では55.31%となった。

\[
55.31\% - 54.41\% = 0.80\text{ポイント}
\]

この結果から、対象データにおいては \(\gamma=2050\) が \(\gamma=400\) より高い的中率を示した。

ただし、K値の調整、直近成績補正、先発投手補正などはまだ検証していない。そのため、どの補正が有効であるかは現時点では結論づけない。

## 3. 今後の実装方針

今後は、現在の「Elo＋ホームアドバンテージ＋\(\gamma=2050\)」を基準モデルとして、以下の補正候補を個別に追加・比較する。

1. K値の調整
2. チームの直近成績による補正
3. 先発投手の試合前成績による補正

先発投手補正は有力な候補の一つとして扱うが、導入前に有効性を仮定しない。補正の有無、および補正方法ごとの予測精度を比較し、効果を検証する。

## 4. 先発投手補正の仮説

先発投手補正では、当日のホーム先発投手ERAを \(ERA_H\)、アウェー先発投手ERAを \(ERA_A\) とし、次の補正式を候補として検討する。

\[
S = \alpha(ERA_A - ERA_H)
\]

\[
D = R_H - R_A + H + S
\]

ここで \(\alpha\) はERA差をElo差へ換算する係数である。

この補正が有効か、またERA以外のWHIP・FIP・Pitching+の方が適するかは未検証である。実装後に、補正なしモデルと比較して判断する。

## 5. 評価方法

各モデルを同一の評価期間で比較する。

- Accuracy：勝敗予測の正解率
- Brier Score：予測確率と結果の二乗誤差
- Log Loss：実際の結果に割り当てた予測確率の評価

補正候補については、次のように比較する。

| モデル | 検証内容 |
|---|---|
| 基準モデル | Elo＋ホームアドバンテージ＋\(\gamma=2050\) |
| K値調整モデル | K値を変えた場合の改善 |
| 直近成績補正モデル | 直近の勝敗・成績を加えた場合の改善 |
| 先発投手補正モデル | 試合前ERA等を加えた場合の改善 |

最終的には、AccuracyだけでなくBrier Score・Log Lossも確認し、どの補正が確率予測として有効かを判断する。
